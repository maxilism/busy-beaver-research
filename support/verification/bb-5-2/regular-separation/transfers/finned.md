# Finned #3: beyond regular inseparability

The [literal table for 10756090](https://api.bbchallenge.org/machine/10756090) is `1RB1RE_1LC1RB_0RA0LD_1LB1LD_---0RA`; `E0` has no successor. In canonical state-before-bit notation let `C(n,m)=(10)^n A0 1^m`. [Iijil's 2023 argument](https://discuss.bbchallenge.org/t/10756090-is-irregular/137/1) gives the return `C((n+m)/2+1,n+1)` when `n+m` is even and a halt otherwise. Blank visits all diagonal pairs. A nonzero difference is repeatedly negated and halved until it is odd, so every off-diagonal pair halts. **No regular ordinary separator** is Iijil's conclusion, not the extension here.

**Extension. No linear context-free language is an ordinary separator.** A linear grammar has at most one nonterminal on each rule's right side. Look *within* the first pass, at the words

```
S(d,b,a) = (10)^d B 1^(b+1) 0 1^a .
```

For `1≤k≤n`, the first pass from `C(n,m)` visits `S(n−k,m+k,k)`. For the first such word, A0 writes one; B crosses the `m` ones and fills the next zero. C erases the preceding one, D crosses back over `m` ones and fills the last zero of `(10)^n`, entering B on its left. For subsequent words, from `S(d,b,a)` with `d≥1`, the same B/C/D sweep moves the zero between the two runs of ones and gives `S(d−1,b+1,a+1)`. This is a literal-table argument, not an assumption that all intermediate configurations have checkpoint shape. In particular, for `a≥1, b≥a`, the word `S(d,b,a)` is reached from `C(d+a,b−a)`: it is on the blank orbit if `b=d+2a` and eventually halts otherwise.

Suppose a linear separator exists. Intersect it with the regular shape `(10)^+ B 1^+ 0 1^+`; the result is still linear (annotate each nonterminal by the input/output states of the DFA for the shape). The linear pumping lemma gives a constant `p` and a factorization `uv w xy` with `|uvxy|≤p`, `|vx|>0`, allowing `v,x` to be repeated together. Indeed, in a shortest derivation of a long word a nonterminal repeats within boundedly many initial productions on its single spine, adding boundedly many terminals at the two outer ends and at least one in total. Apply this to the accepted `S(N,3N,N)` with `N>p`. Repeating the two factors once holds `b=3N` fixed; it can only enlarge the alternating prefix or final run of ones. Since the pumped word is still in the regular shape, it is `S(d',3N,a')` with `d',a'≥N`, one strict, and `a'≤N+p≤3N`. Thus it halts by the first-pass calculation, a contradiction. This excludes one-turn pushdown separators as well ([Ginsburg–Spanier, *Finite-Turn Pushdown Automata*](https://doi.org/10.1137/0304034)). It does **not** exclude all context-free languages.

**Why the distinction matters.** The prior [BusyCoq proof, `Finned3.v`, lines 21–69](https://github.com/meithecatte/busycoq/blob/912afa5230408fb8fc52d67e51855ea0a82a89c7/verify/Finned3.v#L21-L69) uses ten shapes, each with one linear equality in the exponents of fixed blocks. It reflects the public table. Its [step tactic](https://github.com/meithecatte/busycoq/blob/912afa5230408fb8fc52d67e51855ea0a82a89c7/verify/Finned.v#L96-L99) uses one step and then reflexivity, so the union contains blank, has no `E0`, and is closed under each step, not just a return. In public word orientation this union has a **nondeterministic one-counter** recognizer: guess the shape and block boundaries, add each block's constant signed coefficient per repetition, and test the equality at the end. Finite control stores the sign and handles bounded updates with ε-moves; reflection and canonical trimming can instead be done on the shape specifications. There is no one-turn promise. This upper conclusion relies on the published proof, read but not rebuilt here. [Blanchard's 2024 summary](https://discuss.bbchallenge.org/t/bb5s-finned-machines-summary/234/1) already discusses the equality-based invariants.

There is therefore no state-cost function under the helix paper's **global** ordinary-separation requirement. For a different, local classification question, requiring only the right answer on reached/halting inputs of span ≤`W` costs at least `floor((W−1)/3)+1` NFA states for `W≥1`: take `C(i,i)`, `0≤i≤floor((W−1)/3)`, and splice at A. A linear-size NFA suffices for that local question: guess a BusyCoq shape, test its equality modulo `CW+C` instead of over the integers, for a sufficiently large fixed `C`. For canonical span ≤`W` every exponent in those shapes is `O(W+1)` (only bounded literal end blanks can be trimmed; the repeated pieces contain ones), so the modular test there is exact. This is **not** a certificate that rejects the entire halting basin at all spans.
